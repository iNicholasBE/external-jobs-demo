How it works (External Jobs + Webhooks)

  1. You submit a prompt — JobRunr creates an External Job
  2. The trigger uploads a one-line JSONL file and creates a Gemini batch job
  3. The External Job enters PROCESSED state — no polling, no worker thread
  4. Google POSTs a signed webhook (batch.succeeded) to this app when ready
  5. We verify the HMAC signature, download the output file, and signal the job
